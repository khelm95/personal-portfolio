
# My Personal Portfolio

## Project Overview
This website is my personal portfolio. It includes a home page, projects page, and about/contact page. The website uses a consistent purple and lavender color palette and is designed to be responsive and accessible.

## Accessibility Improvements
- Added descriptive navigation labels to help screen reader users identify the main navigation.
- Added skip links to all three pages so keyboard users can jump directly to the main content.
- Added visible keyboard focus indicators to help users see which link or form element is selected.
- Used descriptive alt text for images.
- Checked text and background color combinations using the WebAIM Contrast Checker. The combinations tested passed WCAG AA requirements.
- Added labels, required fields, and built-in browser validation to the contact form.

## Visual Design and Gestalt Principles

### 1. Proximity
I used proximity to group related information together. The contact form labels are placed close to their input fields, making it easier for visitors to understand which information belongs in each field.

### 2. Similarity
I used similarity by keeping the same purple and lavender colors, fonts, and styling across all three pages. This creates a consistent appearance and helps visitors recognize that each page belongs to the same website.

## Contact Form
The About/Contact page includes a contact form with labeled name, email, and message fields. A fieldset and legend group the contact reason options. Required fields and email validation help users identify information that needs to be corrected.

## Accessibility Testing
I tested all three pages using WAVE. Each page received a 10/10 AIM score, with zero errors, zero contrast errors, and zero alerts.
